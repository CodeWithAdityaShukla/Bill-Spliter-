💰 3D Bill Splitter Application

An interactive, responsive 3D web application designed to simplify group expense splitting. Built using pure HTML, CSS, and JavaScript, this app features real-time calculations, custom tip/tax options, and immersive 3D UI elements.

🚀 Live Demo

Check out the live web application here:

[🚀 View Live Demo](https://CodeWithAdityaShukla.github.io/Bill-Spliter-/)

✨ Key Features

3D Visual Interface: Smooth depth effects and modern glassmorphism styling.

Instant Calculation: Dynamic updating of individual shares, tip amounts, and total cost as inputs change.

Flexible Bill Splitting:

Equal split among group members.

Custom tip percentage toggle or manual entry.

Tax calculation options.

Fully Responsive: Optimized for desktops, tablets, and mobile browsers.

Zero Dependencies: Built entirely with native web technologies—lightweight and fast loading.

🛠️ Built With

HTML5: Semantic layout and input elements.

CSS3: Custom 3D perspective, transitions, flexbox, and CSS grid layout.

JavaScript (ES6+): Event listeners, dynamic DOM manipulation, and math calculation functions.
